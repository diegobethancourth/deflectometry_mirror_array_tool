SMOTS Live Simulator

How it works
This page ray-traces the image your camera would record, then runs the full SMOTS retrieval on it — shear, FFT, phase, angle — and compares the recovered tilt against the tilt you commanded. It is the same algorithm as the Python package, reimplemented in the browser, so you can see the loop close in real time.

View
Model limits. Orthographic camera, flat mirrors, single reflection, no lens distortion or defocus. The retrieval works in fractions of a period, which is magnification-invariant, so this exercises exactly the arithmetic that matters — but it is not an optical-design model.
