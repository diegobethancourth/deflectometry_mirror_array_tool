1. Notation and coordinate frames

Read this page first. Two of the three sign conventions below are places where a printed equation and a standard software convention disagree, and each one silently inverts an angle.

1.1 Coordinate frames

The mirror array lies in the plane z = 0 with nominal surface normals along +z. The screen is a plane in front of it, nominally parallel, at perpendicular distance zd. The camera looks back along −z. Node labels run in reading order, so the centre of a 3×3 array is M5 — matching the mechanical assembly drawings.

A tilt component is named after the screen axis it moves: θx rotates the surface normal toward +x and therefore shifts the observed pattern along the screen's x axis. Keeping that naming consistent end to end is what lets you put θx in and get θx back out.

1.2 The three sign conventions

WhereWhat is writtenWhat this work uses
Fourier shift
theorem		 Eq. (5.2) is printed as e−i2πfΔF(f) The standard forward transform gives e+i2πfΔF(f) for that same shift. Positive phase here means the pattern moved toward +x.
Tilt from
screen shift		 Eq. (5.12) as printed subtracts the final arctangent from the initial one That order returns a negative angle for a normal rotating toward +x. The order is reversed here so the sign reads naturally.
Image row
direction		 — Camera frames store row 0 at the top, so the row index runs against world +y. The y shift is negated. Omit this and x reads correctly while y inverts.
Why this matters. None of the three changes any magnitude, so no residual, no RMS and no consistency check will catch them. A mirror tilted one way is simply reported as tilted the other. Confirm the signs against a commanded actuator move before trusting any measurement.

3. Array configuration

Sizing the array against the screen and the camera. Implemented in index.html.

3.1 Screen pixel pitch

p = W / Nx
(3.1)
W screen width  ·  Nx horizontal pixel count. Nominally 344 mm / 3840 = 89.6 µm. This number multiplies every angle the system reports (§ 5.6), which is why it is worth measuring under a microscope rather than dividing datasheet figures.

3.2 Fringe pitch

Pf = n · p
(3.2)
n pixels per fringe. The physical period of the pattern on the screen, in mm.

3.3 Array extent

L = nc a + (nc − 1) g
(3.3)
nc columns  ·  a mirror side  ·  g inter-mirror gap. The same form gives the height from the row count.

3.4 Fringes across the array

Nf = L / Pf
(3.4)
Target Nf ≥ 60 for reliable phase extraction; below about 40 the measurement degrades. This is the headline sizing constraint.

3.5 Screen angular field

θ = 2 arctan( Ws / 2d )
(3.5)
The angular extent the screen subtends from the array at distance d. The array must fall inside it, or the outer mirrors reflect past the panel edge.

3.6 Camera angular field

AOV = 2 arctan( s / 2f )     FOV(d) = 2d tan(AOV/2)
(3.6)
s sensor dimension  ·  f focal length. The covered field at the mirror plane must exceed the array extent from (3.3), else the outer nodes fall outside the frame.

3.7 Surface flatness

Δz ≤ λ/4  →  ≤ 137 nm   (actual ≤ 55 nm at λ/10)
(3.7)
A property of the mirrors, not of the measurement. It sets the floor the measurement is trying to certify; the measurement's own error must sit well below it (§ 7.8).

4. Fringe generation and phase-shift coding

What is displayed on the screen, and what a conventional N-step measurement extracts from it. Implemented in fringes.html.

4.1 Projected intensity

Ik(x) = A + B cos( 2πx/n − 2πk/N )
(4.1)
A bias (mean grey level)  ·  B modulation amplitude  ·  k = 0 … N−1 the step index. Requires A ± B to stay inside 0–255: a clipped sinusoid is no longer sinusoidal, and the clipping biases the retrieved phase rather than merely adding noise.

4.2 N-step phase retrieval

φ = arctan2( Σk Ik sin(2πk/N) ,   Σk Ik cos(2πk/N) )
(4.2)
Wrapped to (−π, π]. This is the classical approach and it needs N captured frames per measurement. SMOTS (§ 5) does not use it — that is the central difference between the two methods and the reason SMOTS is fast.

4.3 Phase uncertainty

σφ = √(2/N) · σI / B / √M
(4.3)
σI per-pixel intensity noise in grey levels  ·  M frames averaged. More steps, more modulation and more averaging all help, and all cost time. This feeds the error budget as its only genuinely random term.

4.4 Screen-position error from phase noise

δxs = σφ · Pf / 2π
(4.4)
A coarser fringe turns the same phase noise into a larger position error, which is the resolution half of the resolution-versus-range trade that § 5.9 formalises.

4.5 Gamma pre-compensation

Iout = 255 · ( Ilin / 255 )1/γ
(4.5)
Panels apply a transfer curve of roughly γ ≈ 2.2. Pre-compensating makes the emitted irradiance sinusoidal rather than the commanded grey level. Left uncorrected, γ injects a second harmonic that lands directly in the retrieved phase.

5. SMOTS: sheared Fourier tilt retrieval

The method this research is built on. One pattern is displayed and never moved; one reference frame is captured; every later frame is compared against it. Implemented in smots/analysis.py and smots/geometry.py, after Choi et al. [1].

The idea in one sentence. Subtract the reference image from the measured image, and the amplitude of what is left tells you how far the pattern moved — because subtracting two copies of the same sinusoid offset by Δ leaves a sinusoid whose amplitude grows with Δ.

5.1 The shear theorem

FT[ f(x) ] = F(f)
(5.1)
FT[ f(x+Δ) ] = eiψ F(f),    ψ = 2πfΔ
(5.2)
S(f) = FT[ f(x+Δ) − f(x) ] = ( eiψ − 1 ) F(f)
(5.3)
A shift is a phase ramp in the Fourier domain, so the sheared pattern — the difference of the two frames — has the same frequency as the original but an amplitude set by the shift. Everything else follows from (5.3).

5.2 Phase from the magnitude ratio (as published)

| S/F |2 = 2 − 2 cos ψ  →  ψ = arccos[ 1 − ½ | S/F |2 ]
(5.4)
Uses only magnitudes, so it returns an unsigned angle in [0, π]. The direction has to be recovered separately, from the sign of the imaginary part.

5.3 Phase from the complex ratio (recommended)

S/F = eiψ − 1  →  Re = cos ψ − 1,   Im = sin ψ
(5.5)
ψ = arctan2( Im(S/F) ,   1 + Re(S/F) )
(5.6)
Why prefer (5.6). It is signed, spans the full (−π, π] without a separate sign step, and stays well conditioned where (5.4) does not. The derivative of arccos is unbounded at ψ → 0 and ψ → π — precisely where small shifts and near-wrapping shifts live. Both are implemented; they agree away from those corners, and the test suite checks that they do.

5.4 Locating the carrier

The carrier is found in the camera's own spectrum rather than assumed. Its bin index is aperture / period, both measured in the same units, so the camera magnification never enters — which is what makes the method robust to an uncalibrated imaging scale.

5.5 Phase to length on the screen

Δ = ( ψ / 2π ) · Pf
(5.7)
A phase fraction of a period is invariant under magnification; multiplying by the physical period on the screen converts it to millimetres. This is the step where the screen pixel pitch (3.1) enters, and the only place it does.

5.6 Screen point seen through the mirror

xf = xi + Δ
(5.8)
xi the screen point seen in the reference frame  ·  xf the point seen now.

5.7 Tilt angle

θ = ½ [ arctan( (xf − x0) / zd ) − arctan( (xi − x0) / zd ) ]
(5.9)
x0 the mirror's own position along the axis  ·  zd mirror-to-screen distance. The factor of ½ is the physics: rotating a mirror by θ swings the reflected ray by 2θ, so the observed motion is twice the angle you are measuring.

5.8 Paraxial form

θ ≈ Δ / ( 2 zd )
(5.10)
Valid near the axis and for small angles; agrees with (5.9) to better than 0.1 % for a mirror within a few percent of zd off axis. Useful as an independent check that the full form is wired up correctly.

5.9 Resolution and unambiguous range

δθ = ( σφ / 2π ) Pf / ( 2 zd )     θmax = ± Pf / ( 4 zd )
(5.11)
The trade in one line: a finer fringe buys resolution and costs range, in exact proportion. The shift wraps at ±Pf/2, hence the factor 4.

5.10 Breaking the 2π ambiguity

Two carriers of different period are displayed at once. Each reports its shift only modulo its own period, and the true shift is the one both agree on. The pair realigns at the least common multiple of the two periods, so consistent solutions repeat forever at that spacing — taking the globally best-agreeing candidate returns an arbitrary alias. The correct rule is to keep every candidate that agrees within tolerance and select the one nearest a prior (zero, or the previous measurement).

Λbeat = P1P2 / | P1 − P2 |
(5.12)
Beat period is not the repeat. Writing P2/P1 = p/q in lowest terms, solutions actually repeat at pP1 = (p−q) Λbeat. So a 4:3 pair repeats exactly at the beat, while a 5:3 pair repeats at twice it. Quoting the beat under-claims the range, which is the safe direction.

Choosing the periods is a real trade: closer periods lengthen the range, but a carrier's FFT bin index is aperture/period, so nearly equal periods land in nearly the same bin and cannot be separated at all.

5.11 Digital apertures

A binary mask is applied per mirror segment, and the analysis runs independently inside each. This is what makes the measurement simultaneous: every segment is its own small interferogram inside one camera frame, and all of them are solved from the same pair of images. The averaged result within an aperture is analogous to a Shack–Hartmann lenslet averaging the wavefront over its own footprint.

aperture width / Pf  ≥  3 periods
(5.13)
Below roughly three periods across an aperture the Fourier peak is too broad to locate reliably, and the segment should be treated as unmeasured rather than trusted.

5.12 Common-mode rejection

Δθi = θi − medianj( θj )
(5.14)
Watching every segment at once means a global disturbance — the bench drifting, someone leaning on the table — appears as common motion across all of them and can be subtracted, leaving the genuine relative change on the node that actually moved.
Relative, not absolute. Every angle from (5.9) is measured against the reference capture. Absolute orientation requires a separate absolute reference, which is why the original work cross-checked against an autocollimator. Screen-pose calibration (§ 8) likewise needs absolute screen coordinates, so unwrapped phase, not the relative shift.

6. Mirror tilt and piezo actuation

Where each mirror has to point, and whether the hardware can get it there. Implemented in piezo.html.

6.1 Incident and reflected directions

û = ( M − C ) / ‖ M − C ‖     v̂ = ( S − M ) / ‖ S − M ‖
(6.1)
C camera  ·  M mirror centre  ·  S screen centre. û runs from camera to mirror, v̂ from mirror to screen.

6.2 Law of reflection, solved for the normal

v̂ = û − 2 ( û · n̂ ) n̂  ⇒  v̂ − û = −2 ( û · n̂ ) n̂  ⇒  n̂ ∝ v̂ − û
(6.2)
The usual statement of reflection is a forward model; rearranged, it inverts directly. The surface normal bisects the incoming and outgoing rays, so a mirror's required orientation follows in closed form — no iteration. The sign of n̂ is fixed by requiring it to face the camera.

6.3 Tilt components from the normal

θx = arctan( nx / nz )     θy = arctan( ny / nz )     θtot = arccos( nz )
(6.3)

6.4 Splitting the baseplate from the piezos

θbase = meani( θi )     θpiezo,i = θi − θbase
(6.4)
This split is the design. Every mirror needs a large, nearly identical fold angle to route the camera onto the screen, plus a small differential that varies across the array. The common part is set once, mechanically, by how the baseplate is bolted. Only the differential has to come from the actuators. Charging the piezos for the whole fold overstates their job by several times and makes an otherwise feasible design look impossible.

6.5 Actuator displacement

Δ = L tan θpiezo
(6.5)
L lever arm from mount pivot to actuator. One actuator per axis.

6.6 Angular resolution

δθ = δΔ / L     δs = 2 δθ d
(6.6)
One actuator step of δΔ tilts the mirror by δθ and walks the reflected spot δs on the screen — again the factor 2 from § 5.7. Compare δs against the fringe pitch to see whether a single step is even resolvable.

6.7 Range budget

θmax = min[ θmount ,   arctan( T / 2L ) ]
(6.7)
T total actuator travel. Whichever limit binds first is the real one. A motorised node is capped by both; a hand-set reference node only by the mount's own adjuster range, since nothing is driving it.

6.8 Controller channel budget

Nmotorised ≤ ⌊ channels / 2 ⌋
(6.8)
A tip/tilt node consumes two channels. A KIM101 offers four, so one controller drives at most two nodes — a hard constraint on how much of the array can ever be actuated.

7. Measurement error budget

Propagating every screen-side uncertainty into a slope error, then into a height error. Implemented in budget.html.

7.1 Slope sensitivity

δs = δxs / ( 2 d )
(7.1)
A slope change δs rotates the reflected ray by 2δs, walking the screen point by 2δs d. Inverting gives the sensitivity: every screen-position error divides by 2d to become a slope error. Longer standoff is free accuracy here.

7.2 Contributors

TermSlope errorCharacter
Phase noiseδxs / 2d, from (4.4)random — uncorrelated pixel to pixel
Screen poseδxcal / 2dtilt-like — uniform across the aperture
Screen planarityδxplan / 2dfigure — correlated across the aperture
Distance errors · δd / dscale — proportional to the true slope

7.3 Quadrature sum

δsRSS = √( Σi δsi2 )
(7.2)
Valid while the terms are independent. A common-mode calibration error shared between them would add linearly instead, and this would understate it.

7.4 Integration into height — one rule per character

random:   δz = δs √( L · Δx )
(7.3)
figure:   δz = δs · L
(7.4)
tilt-like:   δz = 0  (removed by the piston-and-tilt fit)
(7.5)
scale:   δz = sag · δd / d
(7.6)
Do not integrate every term the same way. Slope errors do not share a single propagation rule, and treating them as though they do is a common and expensive mistake. Random noise averages down as a random walk over the aperture. Correlated figure error does not average at all and integrates coherently — a penalty of L/√(LΔx), which for this bench is a factor of about fifty. A uniform screen-pose offset gives every point the same slope error, which is a pure tilt and is therefore removed exactly by the reconstruction's low-order fit — it contributes nothing, not merely a little.

7.5 Lateral registration

δzreg = s · δxreg
(7.7)
Attributing a measured slope to the wrong point on the surface costs height in proportion to the local slope itself.

7.6 Against the surface specification

δztot = √( Σi δzi2 )   vs   λ/10
(7.8)
Slope is the honest deliverable. Deflectometry measures slope directly; height is an integrated, assumption-dependent quantity. Reaching λ/10 in absolute height demands the screen geometry be known to a few micrometres, which is a far harder requirement than reaching good slope accuracy. Quote slope as the primary result and treat height as what it costs you if the geometry is only known as well as it is.

8. Screen-pose calibration through the mirrors

Where zd should come from. Implemented in smots/calibration.py; formulation developed from the geometry for this work, structured after the conventional linear-then-nonlinear approach [2].

The camera never sees the screen — it looks at the mirrors. So the screen's pose has to be recovered through the reflection. This matters because § 7 finds screen geometry dominating the whole error budget, and (5.9) needs zd.

8.1 Plane reflection

H(n̂, e) :   R = I − 2 n̂ n̂T,    t = 2 e n̂
(8.1)
The Householder reflection through the plane { x : n̂·x = e }. It is an involution — reflecting twice returns the identity — and its determinant is −1, so it flips handedness. What the camera sees through a flat mirror is a virtual screen, and the real screen is that virtual one reflected back through the mirror plane.

8.2 The ray-correspondence constraint

Each observation is a triple: a point P on a mirror of known normal, the direction r̂ the camera ray travels after reflecting there, and the screen coordinate q = (u, v) that the decoded absolute pattern says is seen at that point. The screen point must lie somewhere on that reflected ray:

Rq + t = P + λ r̂
(8.2)
( I − r̂ r̂T ) ( Rq + t − P ) = 0
(8.3)
Projecting perpendicular to the ray eliminates the unknown length λ, leaving two independent constraints per observation on the six-DOF pose.

8.3 Linear solution

Since q always has zero third component, the data constrains only the first two columns of R. Solve the nine unknowns [r1, r2, t] by least squares, orthonormalise [r1 r2] by SVD, and take r3 = r1 × r2.

8.4 Nonlinear refinement

minR,t   Σi ‖ ( I − r̂i r̂iT )( Rqi + t − Pi ) ‖2
(8.4)
Gauss–Newton over all six degrees of freedom, with the rotation incremented through a Rodrigues parameterisation. This removes the bias the orthonormalisation step introduces.

8.5 Conditioning — and the degenerate case

κ = λmin[ Σi ( I − r̂i r̂iT ) ] / N
(8.5)
A perfectly flat array cannot be calibrated at all. Each observation constrains the screen only across its ray, never along it. If every mirror normal is identical then every reflected ray is parallel, the sum in (8.5) is singular, and zd is not poorly determined — it is not determined, for any quantity of data.

The remedy is counter-intuitive: do not set the reference mirrors parallel. A few degrees of deliberate spread makes the depth observable. Measured on the synthetic bench with 50 µm decode noise, the zd error falls from unobservable at 0°, to 0.345 mm at 0.5°, 0.078 mm at 2°, and 0.018 mm at 8°. Stepping only the motorised node helps far less, because it is one node in nine.

8.6 The screen pitch measures itself

k = ½ ( ‖r1‖ + ‖r2‖ )    (should be 1)
(8.6)
A free diagnostic. If q is expressed in millimetres, the recovered screen axes must come out unit length. They do not if the assumed pixel pitch is wrong, and the deviation is the scale error — on exactly the number (3.1) that has to be measured under a microscope. The calibration therefore checks its own most important input.

8.7 Extracting what Eq. (5.9) needs

zd = | ( t − o ) · n̂screen |     tilt = arccos | n̂array · n̂screen |
(8.7)
zd is the perpendicular distance from the array origin to the screen plane — not the distance to the screen's origin, which for a tilted screen is a larger number. The tilt says how far the screen is from parallel; (5.9) assumes parallel, so any non-zero tilt is an error term otherwise absorbed silently into every reported angle.
Two prerequisites. Calibration needs absolute screen coordinates, so unwrapped phase — the relative SMOTS measurement never needs to know which fringe it is on, but this does. It also needs mirror normals in advance, which is circular since normals are what SMOTS measures. Break the loop with the mechanical normals of the reference nodes, which are set once and stable, or with an autocollimator; then calibrate; then measure.

9. Sign conventions: three traps, collected

Each of these was found by a numerical test disagreeing with a ray-traced forward model, not by reading an equation. Each inverts an angle while leaving every magnitude, residual and consistency check untouched.

TrapSymptomResolution
Transform
sign		 Every recovered shift has the wrong sign. Magnitudes are perfect, so nothing flags it. Eq. (5.2) as printed uses the opposite exponent sign to the standard forward transform. Eq. (5.4) is immune since it takes a magnitude; (5.6) is not. Fix the convention once, then test it.
Arctangent
order		 All tilts report with reversed polarity: a mirror tilted one way reads as tilted the other. Eq. (5.9) as printed subtracts the final term from the initial one, returning a negative angle for a normal rotating toward +x. Reverse the order, or negate.
Image row
direction		 x is perfect and y is inverted — which looks exactly like a swapped actuator cable. Row 0 is the top of the frame, so the row index runs against world +y. Negate the y shift once, at the point where image indices become world coordinates.
How to check on the bench. Command a known actuator move on the motorised node and confirm the reported angle changes in the expected direction and by roughly the expected amount. One deliberate move validates all three at once, and nothing else will.
