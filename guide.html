Start Here — how the five tools fit together

What this toolkit is for

A flat mirror reflects a pattern shown on a screen into a camera. Tilt the mirror and the reflected pattern shifts — measure the shift and you have measured the tilt. Do it for nine mirrors at once and you can watch a whole segmented surface simultaneously. That is deflectometry, and the specific method here is SMOTS.

These five pages answer the five questions you have to settle before the bench can work. They are not independent: each one hands numbers to the next. The chart below shows what flows where. Every box is clickable.

When a page turns amber or red

Every page shows a verdict banner. Red does not mean the tool is broken — it means the design does not close, and it tells you which page to go back to.

What you seeWhat it meansWhere to fix it
Fringes Nf < 40 Too few fringes across the array to extract phase reliably Lower pixels-per-fringe, or add columns, on Array Config
Camera FOV too small The lens cannot cover the whole array at that distance Shorter focal length or bigger sensor on Array Config
Intensity clips A ± B leaves the 0–255 range, so the sinusoid is truncated — this biases the phase, it does not merely add noise Lower modulation or re-centre bias on Fringe Generator
n < 8 px per fringe The panel renders a stepped near-square wave; harmonics leak into the phase Raise pixels-per-fringe on Fringe Generator
Controller over budget A tip/tilt node needs 2 channels and a KIM101 has 4 — so two nodes, maximum Fewer motorised nodes, or a second controller, on Tilt & Actuation
Piezo out of range A mirror needs more tilt than the mount or actuator can give Check the baseplate pre-tilt, add standoff, or shrink the array
Slope target missed The measurement will not be accurate enough The bar chart on Error Budget names the dominant term
Error reads “wrap” Tilt exceeded the unambiguous range, so the phase folded back Coarser carrier or shorter screen distance on Simulator

First time here? Do these four things
Open the SMOTS Simulator and tilt M5. Watch the fringes on that one mirror shift while the others stay put. Then set the right-hand panel to Sheared pattern: eight mirrors go blank and only M5 carries fringes. That single picture is the method — subtracting the reference leaves only what moved.
Press “+1 actuator step”. The mirror moves about 1.05 µrad — one step of a real MPIA10 — and the retrieval still resolves it. That is the sensitivity you are working with.
Walk the chain: 1 → 2 → 3 → 4. On each page, read the Mathematics panel on the right while you move a slider on the left. Each equation shows its current numbers, so you see cause and effect rather than a formula.
Press Guided tour in the top bar of any page. It walks you through that page's controls and outputs one at a time. Arrow keys move, Escape closes.
One habit worth forming. Change one control at a time and watch which metric tile reacts. Every number on every page is live, so the tool is at its most useful as an instrument for building intuition — not as a calculator you read once. The full derivations are in the mathematical reference in the repository if you want to go deeper.
